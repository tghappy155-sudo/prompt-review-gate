# 可选的全局规则

将以下内容追加到你的 Codex 全局 AGENTS.md 中。保留原有规则，不要整份覆盖。此文件是安装示例，不会自动修改你的配置。

```markdown
## 先优化提示词，再审核执行

对新的需求，先使用 $prompt-review-gate 生成一个简洁可执行的待审核提示词，明确意图、范围、交付与验收标准；不只压缩或复述，不扩展原任务。待我确认后再执行，审核前不开展原任务的搜索或外部操作，上级指令要求除外。确认、修订、补充材料和已批准任务的继续执行按技能处理，避免重复审核。遵从我最新明确的跳过或关闭指示；不覆盖系统、开发者指令或权限边界。
```

默认位置为 `~/.codex/AGENTS.md`；设置了 CODEX_HOME 时使用该目录。若存在非空 AGENTS.override.md，应先检查实际加载的文件。项目级规则可能覆盖全局偏好，因此这不是绝对优先级开关。
